# ekys-ig-medya

[@ekys_sinavi](https://www.instagram.com/ekys_sinavi/) Instagram hesabının otomatik paylaşımları için geçici medya deposu.
Paylaşım sırasında Instagram görsel/videoyu buradan (GitHub Pages) indirir; depoda yalnız o an paylaşılan içerik durur.

Bu hesap MEB veya ÖSYM'nin resmî hesabı değildir. Site: https://ekyssinavi.com
